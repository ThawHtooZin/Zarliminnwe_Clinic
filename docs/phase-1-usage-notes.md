# Phase 1 Usage Notes

## Login

- Default admin email: `admin@zarliminnew.test`
- Default admin password: `password`

## Products And Units

1. Create a category first.
2. Create a product with SKU and category.
3. Add unit rows in real packaging order, such as Box, Strip, Pill.
4. For child units, choose the parent row and enter the conversion factor.
5. Example: Strip parent is Box with factor 10 means 1 Box contains 10 Strips.

## Opening Stock

1. Open `Opening Stock`.
2. Select the product and exact unit being posted.
3. Enter quantity, batch, and expiry if required.
4. Submit to create a stock ledger row and update stock balance.

## Purchase Receipts

1. Create a purchase receipt for a supplier.
2. Add each received item with product, exact purchased unit, quantity, and cost.
3. Save the receipt as draft.
4. Open the receipt and click `Post Receipt`.
5. Posting creates stock ledger rows and updates balances.
